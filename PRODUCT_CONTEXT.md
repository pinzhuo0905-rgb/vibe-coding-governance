# Product Context & User Profile

> **Document Status:** Single Source of Truth for Product Positioning, User Mental Models, and UI Density Strategy.

---

## 1. Product Identification
- **Product Name:** AI UI & Code Governance Engine (Universal Vibe Coding Governance Platform)
- **Product Category:** Developer Infrastructure & Autonomous Agent Engineering Console
- **Core Value Proposition:** Enforces deterministic code quality, architectural clean boundaries, and professional, anti-slop user interface standards across autonomous AI coding workflows.

---

## 2. Target Users & Skill Profiles
- **Primary Users:** Senior Software Engineers, Engineering Leads, Platform Architects, and DevOps Operators.
- **Secondary Users:** Autonomous AI Coding Agents (Codex, Claude Code, Cursor, Copilot, Gemini).
- **User Technical Sophistication:** High / Expert. Users deeply understand AST analysis, clean architecture, automated testing, WCAG accessibility, and design tokens.
- **Cognitive Demands:** Users scan large sets of data, analyze audit logs, configure security policies, and evaluate rule violations under tight delivery schedules.

---

## 3. Usage Patterns & Environment
- **Session Duration:** Long sessions (2 to 8 hours daily).
- **Primary Form Factor:** Dual-monitor Desktop (1920x1080, 2560x1440) and High-DPI Laptops (1440x900).
- **Secondary Form Factor:** On-call Tablet inspections (768x1024) and emergency mobile status checks (375x812).
- **Lighting Context:** Variable developer environments (dominant Dark Mode preference, high-contrast crisp readability required).

---

## 4. Primary Jobs to Be Done (JTBD)
1. **Instant Health Assessment:** Evaluate repository governance health score, failing gates, and security alerts in < 5 seconds.
2. **Rule & Token Enforcement:** Audit AST rules, token adherence, and architectural boundaries with zero ambiguity.
3. **Autonomous Agent Oversight:** Inspect AI agent repair attempts, root-cause analyses, and visual screenshot diffs.
4. **Fast Configuration:** Manage token values, component variants, and security exemptions without navigating nested modal wizards.

---

## 5. High-Frequency Actions
- Filtering and scanning audit logs and quality gate runs.
- Triggering repository re-scans and automated screenshot capture.
- Toggling policy rules and updating metric thresholds.
- Copying CLI execution commands and rule identifiers.
- Inspecting visual diffs across responsive viewports.

---

## 6. Information Density & Aesthetic Principles
- **Target Density Profile:** **Medium-High to High**.
- **Aesthetic Classification:** Professional Enterprise Tooling / Engineering Workbench.
- **Layout Priority:** Scannability, structured tables, and clear visual hierarchy over marketing whitespace and decorative spectacle.
- **Brand Personality Attributes:**
  - **Precise:** Exact pixel metrics, clear status indicators, deterministic typography.
  - **Calm:** Low-saturation neutral backgrounds, zero screaming gradients or unprompted animations.
  - **Disciplined:** Strict 4px/8px spatial rhythm, unified 6px corner radiuses, zero nested card mazes.
  - **Transparent:** Immediate visibility into system status, errors, and validation evidence.
