# Design Archetype Reference Catalog

> **Purpose:** Reference guide enabling AI Agents to match interface styling to intentional, distinct design personalities rather than defaulting to generic SaaS averages.

---

## 1. Clinical Precision (Active Archetype)
- **Visual Personality:** Rigorous, scientific, disciplined, high-density, authoritative.
- **Color Palette:** Pure dark slate (`#090d16`), cool grey surfaces (`#0f172a`), crisp 1px borders (`#334155`), precise cyan/emerald accents.
- **Typographic Scale:** Compact sans-serif paired with technical monospace metadata. Max heading 24px.
- **Best Suited For:** Developer consoles, static analysis tools, cloud infrastructure dashboards, security monitoring.

---

## 2. Terminal Noir
- **Visual Personality:** Hacker-centric, dark-first, functional minimalism, ultra-high density.
- **Color Palette:** Deep black (`#050505`), amber or phosphor-green accents (`#f59e0b` or `#22c55e`), minimal borders.
- **Typographic Scale:** Monospace-dominant (`JetBrains Mono`, `Courier New`).
- **Best Suited For:** CLI companions, DevOps logs, runtime telemetry, terminal emulators.

---

## 3. Modern Industrial
- **Visual Personality:** Utilitarian, tactile, heavy borders, mechanical precision, muted earthen tones.
- **Color Palette:** Steel grey, industrial yellow warnings, graphite accents.
- **Typographic Scale:** Dense grotesque sans-serif with bold tabular numerals.
- **Best Suited For:** Hardware monitors, supply chain tracking, manufacturing telemetry.

---

## 4. Warm Craft
- **Visual Personality:** Humanist, thoughtful, tactile, organic warmth.
- **Color Palette:** Warm stone backgrounds, terracotta and olive accents, subtle cream highlights.
- **Typographic Scale:** Serif or humanist sans headers, generous line heights.
- **Best Suited For:** Documentation sites, personal knowledge bases, writing tools.
